手机端三件套 少一个都会出怪现象

  1. ① <meta name="viewport" content="width=device-width, initial-scale=1.0"> —— 不写会整体缩小。
  2. ② * { -webkit-tap-highlight-color: transparent; } —— 去掉点击灰块。
  3. ③ 要接管手势的容器加 touch-action —— 否则浏览器先滚页面，手势坐标断断续续。
