# 贪吃蛇游戏 — 需求规格文档 (spec.md)

> 项目类型：前端网页游戏（《高级网页设计》课程项目）
> 版本：v1.0
> 状态：待确认

---

## 1. 项目概述

### 1.1 项目名称
Snake — 网页贪吃蛇游戏

### 1.2 项目目标
使用原生 HTML5 + CSS3 + JavaScript（无框架）实现一款可在现代桌面浏览器运行的经典贪吃蛇游戏。

### 1.3 技术栈
- **HTML5**：语义化结构，Canvas 或 DOM Grid 渲染游戏区域
- **CSS3**：Flexbox/Grid 布局、CSS 变量、渐变、动画
- **原生 JavaScript (ES6+)**：游戏循环、状态管理、键盘事件、localStorage
- **零依赖**：不使用任何第三方库或框架

## 2. 功能需求

### 2.1 游戏状态机

```
         ↓
     [菜单页] ──开始──→ [游戏进行中]
         ↑                  │ 空格
         │                  ↓
         │              [暂停中]
         │                  │ 空格
         │                  ↓
         │              [游戏进行中]
         │
         └──重新开始── [游戏结束] ← 撞墙/咬自己
```

| 状态 | 描述 | 可触发动作 |
|------|------|-----------|
| 菜单页 | 初始界面，显示游戏标题、难度选择、最高分 | 选择难度 → 开始游戏 |
| 游戏进行中 | 蛇持续移动，玩家控制方向 | 方向键转向、空格暂停 |
| 暂停中 | 游戏冻结，显示暂停提示 | 空格继续 |
| 游戏结束 | 显示最终得分和最高纪录 | 重新开始 / 返回菜单 |

### 2.2 核心玩法

| 项目 | 规格 |
|------|------|
| 棋盘尺寸 | **15 × 15 格**（紧凑棋盘） |
| 蛇初始长度 | 3 格，居中生成，初始方向向右 |
| 食物数量 | 同时存在 **1 个**普通食物 |
| 得分规则 | 每吃 1 个食物 **+10 分** |
| 结束条件 | **蛇头撞墙** 或 **蛇头咬到自身** |
| 最高分 | 通过 **localStorage** 本地持久化保存 |

### 2.3 难度档位

| 难度 | 蛇移动间隔 | 说明 |
|------|-----------|------|
| 简单 (Easy) | 200ms/格 | 入门级，速度较慢 |
| 普通 (Normal) | 130ms/格 | 标准速度（默认） |
| 困难 (Hard) | 70ms/格 | 挑战级，速度很快 |

### 2.4 操作方式

| 按键 | 功能 |
|------|------|
| `↑` / `W` | 向上移动 |
| `↓` / `S` | 向下移动 |
| `←` / `A` | 向左移动 |
| `→` / `D` | 向右移动 |
| `Space` | 暂停 / 继续游戏 |

**边界规则**：不允许蛇直接反向移动（如向右时不能直接向左，需先向上/向下）。

## 3. 视觉设计规范

### 3.1 整体风格
**现代简约风（由设计者决定）**
- 暗色主题，游戏区域与 UI 面板对比鲜明
- 蛇身带渐变色，食物带呼吸动效
- 干净的几何图形，无多余装饰

### 3.2 色彩方案（CSS 变量）

```css
--bg-primary:    #1a1a2e;      /* 页面背景 深蓝黑 */
--bg-board:      #16213e;      /* 棋盘背景 深靛 */
--grid-line:     #0f3460;      /* 网格线 */
--snake-head:    #00ff88;      /* 蛇头 亮绿 */
--snake-tail:    #00cc6a;      /* 蛇尾 深绿 */
--food:          #ff6b6b;      /* 食物 珊瑚红 */
--text-primary:  #eaeaea;      /* 主要文字 */
--text-muted:    #8892b0;      /* 次要文字 */
--accent:        #64ffda;      /* 强调色 青色 */
```

### 3.3 布局结构

```
┌──────────────────────────────────┐
│          游戏标题 + Logo          │
├──────────┬───────────────────────┤
│          │                       │
│  分数面板 │      15×15 游戏区域    │
│  最高纪录 │     (Canvas 渲染)     │
│  难度显示 │                       │
│          │                       │
├──────────┴───────────────────────┤
│      操作提示 & 难度选择菜单       │
└──────────────────────────────────┘
```

### 3.4 动效规格

| 元素 | 动效 | 持续时间 | 缓动函数 |
|------|------|---------|---------|
| 蛇身 | 从头 `snake-head` 到尾 `snake-tail` 的线性渐变 | 静态 | — |
| 食物 | 呼吸缩放 `scale(1) ↔ scale(1.15)` 循环 | 1.2s | ease-in-out |
| 蛇头 | 微缩放（每格移动时） | 100ms | ease-out |
| 按钮 | hover 时背景色加深 + 微位移 | 200ms | ease |
| 游戏结束 | 遮罩淡入 + 结果文字弹跳 | 400ms / 600ms | ease-out / cubic-bezier |

## 4. 技术约束

### 4.1 兼容性
- **Chrome**：最新 2 个版本 ✅
- **Edge**：最新 2 个版本 ✅
- **Firefox**：最新 2 个版本 ✅
- **Safari**：最新 2 个版本 ✅
- **不要求**：IE、旧版浏览器、移动端触屏

### 4.2 性能指标
- 游戏循环帧率稳定（60fps 平滑动画）
- 页面资源加载 < 50KB（零外部依赖）
- 键盘事件响应延迟 < 50ms

### 4.3 代码结构（建议）

```
snake-game/
├── index.html          # 主页面结构
├── css/
│   └── style.css       # 全部样式
├── js/
│   ├── game.js         # 游戏核心逻辑（状态机、循环）
│   ├── snake.js        # 蛇类（移动、增长、碰撞）
│   ├── food.js         # 食物类（生成、位置）
│   ├── renderer.js     # Canvas 渲染模块
│   └── main.js         # 入口、事件绑定、UI 交互
└── spec.md             # 本文档
```

## 6. 验收标准（概述）

1. ✅ 页面加载后显示菜单界面，可选三档难度
2. ✅ 按方向键可控制蛇移动，不能直接反向
3. ✅ 按空格键可暂停/继续游戏
4. ✅ 吃到食物得分 +10，蛇身增长 1 格
5. ✅ 撞墙或咬到自己触发游戏结束
6. ✅ 游戏结束后可重新开始或返回菜单
7. ✅ 最高得分持久化到 localStorage
8. ✅ 视觉风格符合设计规范，蛇身渐变 + 食物呼吸动效
9. ✅ 在 Chrome/Edge/Firefox/Safari 最新版正常运行
