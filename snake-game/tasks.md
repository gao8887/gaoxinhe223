## 任务详情 + 验收标准

---

### T1 — 项目骨架 + 静态页面布局

**目标**：建立项目目录，编写语义化 HTML 结构 + CSS 变量 + 页面布局框架

**文件变更**：
- 新建 `index.html`（DOCTYPE、meta、语义标签）
- 新建 `css/style.css`（CSS 变量定义、Flexbox 布局、暗色主题）
- 新建 `js/` 空目录

**验收清单（手动测试）**：
- [ ] 浏览器打开 index.html，页面显示游戏标题 "Snake"
- [ ] 页面分为三栏：左侧分数面板、中间游戏区域占位、右侧（或底部）操作提示
- [ ] 使用 3.2 节定义的 CSS 变量色板（背景深蓝黑、蛇绿、食物珊瑚红）
- [ ] 布局在 1200×800 窗口下居中对齐，无溢出
- [ ] F12 控制台无错误

**门禁**：✅ 静态页面视觉正确 → 进入 T2

---

### T2 — 棋盘渲染与网格绘制

**目标**：在 Canvas 上绘制 15×15 网格棋盘

**文件变更**：
- 新建 `js/renderer.js`（渲染模块：init、drawBoard）
- `index.html`：游戏区域加入 `<canvas>` 元素
- `css/style.css`：Canvas 尺寸锁定，禁用缩放/拖动

**验收清单（手动测试）**：
- [ ] 刷新页面后，中间区域显示正方形 15×15 网格
- [ ] 网格线颜色为 `--grid-line`，棋盘背景为 `--bg-board`
- [ ] 棋盘尺寸 ≈ 450×450px（每格 30px，适合桌面）
- [ ] F12 Console 无报错，Elements 面板能找到 canvas 元素
- [ ] Resize 窗口时棋盘保持正方形不变形

**门禁**：✅ 网格清晰渲染 → 进入 T3

---

### T3 — 蛇数据模型 + 移动逻辑

**目标**：实现蛇的数据结构（坐标数组 + 方向）和每帧移动计算，**暂不涉及渲染**

**文件变更**：
- 新建 `js/snake.js`（Snake 类：body 数组、direction、move()、grow()、setDirection()）
- 新建 `js/main.js`（入口：初始化 Snake、每 200ms 打印一次蛇头坐标到 Console）

**验收清单（手动测试）**：
- [ ] 打开 Console，能看到每隔 200ms 蛇头坐标 `(x, y)` 在变化
- [ ] 初始时蛇长度为 3，坐标居中偏左，方向向右
- [ ] 蛇头每帧 +1，蛇尾同步 -1（整体前移，长度不变）
- [ ] 坐标边界：x ∈ [0,14]、y ∈ [0,14]，超出时 Console 打印警告
- [ ] **此阶段看不到画面变化**（T4 才会绘制），仅 Console 输出验证逻辑

**门禁**：✅ Console 坐标正确循环 → 进入 T4

---

### T4 — 食物生成与绘制

**目标**：食物随机生成（不与蛇重叠）并在 Canvas 上以圆角方形 + 颜色绘制

**文件变更**：
- 新建 `js/food.js`（Food 类：position、spawn() 随机位置 + 蛇碰撞检测）
- `js/renderer.js`：新增 `drawFood(position)` 方法
- `js/main.js`：初始化 Food 并在 Canvas 上渲染

**验收清单（手动测试）**：
- [ ] 刷新页面，棋盘上出现 1 个红色方块食物
- [ ] 食物不会生成在蛇身上（观察蛇和食物不重叠）
- [ ] Console 打印食物坐标，确认与蛇 body 无交集
- [ ] 手动刷新 5 次，食物每次位置不同

**门禁**：✅ 食物正确生成 → 进入 T5

---

### T5 — 游戏主循环 + 状态机

**目标**：用 `requestAnimationFrame` 或 `setInterval` 构建游戏循环，实现 MENU / PLAYING / PAUSED / OVER 四态切换

**文件变更**：
- 新建 `js/game.js`（Game 类：状态机、loop()、start()、pause()、gameOver()）
- `js/main.js`：改为通过 Game 实例驱动，蛇和食物作为 Game 的内部属性

**验收清单（手动测试）**：
- [ ] 页面加载后显示 **PAUSED** 状态（或 MENU 占位，暂先暂停）
- [ ] 调用 `game.start()` 后蛇开始移动（Canvas 上能看到蛇身）
- [ ] 调用 `game.pause()` 后蛇冻结不动
- [ ] 调用 `game.gameOver()` 后 Console 输出 `[GAME OVER]`
- [ ] Console 打印当前状态 `game.state`，状态值在 4 种之间正确切换

**门禁**：✅ 状态机逻辑正确 → 进入 T6

---

### T6 — 键盘事件 + 方向控制

**目标**：绑定方向键/WASD/空格，实现转向和暂停；禁止 180° 反向

**文件变更**：
- `js/main.js`：document 级别 `keydown` 事件监听
- `js/snake.js`：`setDirection()` 加入反向校验（右→左 非法）

**验收清单（手动测试）**：
- [ ] 按 `→` 蛇向右，`↓` 蛇向下，`←` 蛇向左，`↑` 蛇向上
- [ ] 按 `W/A/S/D` 同样有效
- [ ] 蛇向右时按 `←` 无效（蛇不回头），Console 打印 "Invalid reverse direction"
- [ ] 按 `Space` 暂停，再按 `Space` 继续
- [ ] 快速连按方向键，蛇方向正确跟随，不丢失按键

**门禁**：✅ 方向控制流畅 → 进入 T7

---

### T7 — 碰撞检测 + 得分

**目标**：蛇头撞食物 → 吃食物 +10 分 + 蛇增长 1 格 + 重新生成食物；撞墙或咬自己 → 游戏结束

**文件变更**：
- `js/snake.js`：新增 `headCollidesWithBody()` 方法
- `js/game.js`：loop 中加入碰撞判定逻辑，吃到食物时调用 `snake.grow()` + `food.spawn()`
- `js/renderer.js`：新增 `drawSnake(snake.body)` 方法（绘制蛇身）

**验收清单（手动测试）**：
- [ ] 控制蛇头碰到食物 → 食物消失、蛇身增长 1 格、新食物出现、Console 打印 "+10"
- [ ] 蛇头撞到左右上下任一墙壁 → 游戏停止、Console 打印 "[GAME OVER] Wall collision"
- [ ] 蛇头咬到自己身体 → 游戏停止、Console 打印 "[GAME OVER] Self collision"
- [ ] 蛇增长后不出现身体重叠 bug
- [ ] 吃 5 次食物后蛇长度 = 8（初始 3 + 5 增长）

**门禁**：✅ 碰撞检测无 bug → 进入 T8

---

### T8 — 游戏结束 / 暂停 / 重开 UI

**目标**：替换 Console 输出为 DOM UI 面板，实现完整的菜单/暂停/结束叠加层

**文件变更**：
- `index.html`：增加暂停蒙层、游戏结束蒙层、开始菜单 DOM 结构
- `css/style.css`：蒙层样式、淡入动画、按钮 hover 效果
- `js/main.js`：状态变化时更新 UI 显示/隐藏

**验收清单（手动测试）**：
- [ ] 打开页面显示「开始游戏」菜单（有标题、开始按钮、难度选择）
- [ ] 按 Space 暂停时，棋盘上方出现半透明蒙层 + "暂停中" + 继续按钮
- [ ] 游戏结束时，显示最终得分 + 最高分 + "重新开始" + "返回菜单" 按钮
- [ ] 点击按钮能正确触发对应动作
- [ ] 蒙层出现/消失有淡入淡出动画（300ms）
- [ ] 暂停时蛇确实不动，继续后接着之前的位置走

**门禁**：✅ UI 全部正确 → 进入 T9

---

### T9 — 难度选择 + localStorage 最高分

**目标**：菜单中加入难度选择；最高分持久化到 localStorage

**文件变更**：
- `index.html`：难度 Radio 按钮组
- `css/style.css`：难度选择样式
- `js/game.js`：根据难度设置 `tickInterval`（Easy 200 / Normal 130 / Hard 70）
- `js/main.js`：localStorage 读写逻辑

**验收清单（手动测试）**：
- [ ] 菜单可选择 简单/普通/困难，选中后点开始
- [ ] 简单难度蛇明显慢，困难难度蛇明显快
- [ ] 游戏结束后最高分 > 历史最高时，自动刷新页面时仍保留
- [ ] F12 → Application → Local Storage 能看到 `snake-highscore` 键值
- [ ] 清空 localStorage 后最高分重置为 0

**门禁**：✅ 难度 + 最高分 OK → 进入 T10

---

### T10 — 视觉动效优化

**目标**：蛇身渐变色 + 食物呼吸动效 + 蛇头微缩放

**文件变更**：
- `js/renderer.js`：蛇身用 Canvas `createLinearGradient` 绘制渐变；食物用 `requestAnimationFrame` 驱动呼吸动画（或 CSS 动画 + Canvas 叠加）
- `css/style.css`：按钮 hover 微位移、整体微调

**验收清单（手动测试）**：
- [ ] 蛇身从头部亮绿 (`--snake-head`) 渐变到尾部深绿 (`--snake-tail`)
- [ ] 食物有呼吸效果：缓慢放大缩小（周期 ≈ 1.2s）
- [ ] 鼠标 hover 按钮时，按钮背景加深 + 向下位移 2px
- [ ] 整体画面风格统一，无视觉冲突
- [ ] 动效流畅无卡顿（FPS ≈ 60）

**门禁**：✅ 视觉效果达标 → 全部任务完成，进入阶段 6 Git 收尾
