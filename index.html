COLOPHON / 制作说明

原生，够用，也够美

整站没有框架、没有外部字体、没有 CDN。所有样式写在一个 style 标签里，图标是内联 SVG，AI 截图存放在本地的 ai-shots/ 目录。直接用浏览器打开 index.html 即可浏览；AI 页面要完整体验，需要另起 Node 后端。

  • 零依赖不加载任何远程脚本、样式或字体，断网也能打开目录与静态页面。
  • 相对路径所有链接以本目录为根，移动到 GitHub Pages / Gitee Pages 也不用改代码。
  • 截图说明四张 AI 截图均为本地运行界面，含 URL、接口路径与学号后三位 223。
  • 持续生长新页面追加到对应模块，导航与统计会随课程进度更新。
