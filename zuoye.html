2.2 卡片动画补全参考代码

/* li卡片容器 */
li{
    width:300px;
    overflow:hidden; /*阻止图片放大溢出li容器*/
    position:relative; /*子绝父相*/
}
li img{
    transition: transform 0.5s; /*transition写普通选择器，移入移出都有动画*/
}
/*悬浮图片放大*/
li:hover img{
    transform: scale(1.2);
}
.text{
    position:absolute; /*绝对定位放在卡片底部*/
    left:0;
    bottom:-80px;
    width:100%;
    transition: bottom 0.4s;
}
li:hover .text{
    bottom:0;
}
/*奇数卡片，悬浮文字铺满卡片*/
li:nth-child(odd):hover .text{
    bottom:0;
    height:100%;
}

transition写在普通选择器而不是hover的原因：

写普通选择器：鼠标移入、移出都会执行过渡动画；写hover只有移入有动画，移出瞬间变回原样。

三、手写简答（25分）

1.子绝父相位置关系说明（画图文字描述）：

父盒子设置 position:relative，父盒子本身位置不变；子盒子设置 position:absolute，子盒子脱离文档流，参照这个父盒子进行定位（top/left控制位置）。

2.overflow:hidden本节课两个作用：

①裁剪容器内部溢出的内容；②配合transform缩放，防止图片放大跑出盒子覆盖旁边元素。

3.transform:scale(1.2)是否改变盒子实际占位？是否挤压旁边卡片？

不会改变盒子原始占位大小，不会挤压旁边卡片。transform属于视觉变换，只是渲染上放大，不改变盒子盒模型宽高，不影响文档流。

4.transition写在hover上 vs普通选择器，移出行为差异：

写在hover：鼠标移入有过渡动画，鼠标移出瞬间复原，没有过渡效果。

写普通选择器：移入、移出两个方向都拥有平滑过渡动画。

5.自己写代码遇到bug示例：

现象：卡片悬浮图片放大，图片跑到卡片外面盖住隔壁卡片。排查：li容器没有加overflow:hidden。修复：给li加上overflow:hidden，溢出部分被容器裁剪，不会覆盖其他卡片。
